# 功能预览截图

README 的「功能预览」引用了本目录下的 4 张截图。**请按下面的说明拍摄你的真实
使用截图**，用指定的文件名保存到本目录，GitHub 会自动渲染（无需改 README）。

## 需要拍摄的截图

| 文件名 | 内容 | 拍摄建议 |
| --- | --- | --- |
| `overview.png` | 技能工作台总览 | 打开「技能管理」Tab，展开 `demo-preview-skill` 或任意 skill，右侧显示 `SKILL.md` 预览 |
| `tree.png` | 懒加载目录树 | 展开 skill 后再展开一个子目录（如 `assets/`），展示多级缩进与文件夹图标 |
| `edit.png` | 内联编辑 | 点「编辑」，右侧显示编辑器，可看到修改后的内容与「保存」按钮 |
| `create.png` | 新建 skill 表单 | 点「+ 新建」，弹窗显示表单（写入位置/名称/描述/正文） |

## 拍摄方法

- **macOS**：`Cmd + Shift + 4` 框选面板区域；或 `Cmd + Shift + 5` 整窗/窗口拍摄。
- **Windows**：`Win + Shift + S` 框选。
- 建议把 better-sidebar 面板拉宽到约 800px 再拍，深浅色主题均可，保持横屏 16:10 左右更美观。

## 注意事项

- 文件必须与上表**同名**（如 `overview.png`），格式 png/jpg 均可。
- 提交时这些截图会随仓库一起推送到 GitHub（`screenshots/` 未被 .gitignore 排除）。
- 想替换 README 里的展示宽度/数量？改 `README.md` 的「功能预览」小节即可。
